CATEGORY: TOLERANCES (if in review_scope)
──────────────────────────────────
Required Data Check:
  ✓ Is general tolerance specified anywhere? (title block, notes)
  ✓ Are critical dimensions explicitly toleranced?
  ✓ Is datum structure defined (if GD&T present)?

If required data MISSING → Create RED FLAG:
  Severity: 🔴 CRITICAL if general tolerance missing
  Severity: 🟠 HIGH if critical dimension lacks tolerance
  Severity: 🟡 MEDIUM if datum structure unclear

Red Flag Checks (go through each):

  RF-T1: Missing general tolerance
    Check: Is "UNLESS OTHERWISE SPECIFIED: ±X.XXX" stated anywhere? Or something similar
    If NO → FLAG IT
    Why matters: Untoleranced dimensions undefined

  RF-T2: Critical dimension without explicit tolerance
    Check: List all critical dimensions (bores, shafts, mating surfaces)
    For each: Does it have ±tolerance? Or uses only general?
    If critical uses only general AND general is loose → FLAG IT
    Why matters: General tolerance may be inadequate for function

  RF-T3: Over-specified tolerance (tighter than necessary)
    Check: Each tolerance vs. manufacturing process capability
    Standards: ±0.050"→rough, ±0.030"→standard, ±0.010"→precision, ±0.005"→tight
    If tolerance requires grinding/honing for non-critical feature → FLAG IT
    Why matters: Cost - unnecessary expensive process

  RF-T4: Tolerance tighter than process capability
    Check: If ±0.0001" specified, requires honing (not turning)
    If ±0.002" on turned surface, requires grinding
    If tolerance spec doesn't match typical process → FLAG IT
    Why matters: Either over-specified cost OR impossible to achieve

  RF-T5: Tolerance stack not analyzed (if multiple chained dimensions)
    Check: Do multiple dimensions add up (length = part A + part B + part C)?
    If yes: Calculate worst-case cumulative tolerance
    If worst-case exceeds acceptable range → FLAG IT
    Why matters: Assembly might not fit

  RF-T6: GD&T tighter than size tolerance (logically impossible)
    Check: Compare size tolerance to GD&T tolerance
    Example: ±0.010" size + 0.002" concentricity = 5× tighter GD&T
    If GD&T is much tighter → FLAG IT as contradiction
    Why matters: Contradictory requirements, impossible to satisfy both

CATEGORY: GD&T (if in review_scope)
───────────────────────────

Required Data Check:
  ✓ Are all datums clearly defined? (Triangle symbols visible?)
  ✓ Is datum hierarchy clear? (Primary, secondary, tertiary?)
  ✓ Are critical features GD&T controlled? (bores, cylinders, surfaces)

If required data MISSING → Create RED FLAG:
  Severity: 🔴 CRITICAL if datum undefined
  Severity: 🟠 HIGH if critical feature lacks GD&T
  Severity: 🟡 MEDIUM if datum hierarchy unclear

Red Flag Checks:

  RF-G1: Missing GD&T on critical feature
    Check: List all critical features (bearing bores, rotating surfaces, mating surfaces)
    For each: Is there a concentricity/roundness/runout spec?
    If critical feature has NO GD&T → FLAG IT
    Why matters: No position control, part could be off-center and fail in assembly

  RF-G2: Datum not clearly defined or unmarked
    Check: For each GD&T spec that references "Datum A", is Datum A marked on drawing?
    Look for: Triangle symbols pointing to specific feature
    If "Concentricity to Datum A" but Datum A not marked → FLAG IT
    Why matters: Manufacturer doesn't know which surface is the reference

  RF-G3: Datum hierarchy unclear (primary/secondary/tertiary)
    Check: Is order of precedence stated or obvious from notation?
    Example: Does frame show Datum A | Datum B | Datum C in order?
    If order unclear → FLAG IT
    Why matters: Fixture setup depends on datum order

  RF-G4: Multiple conflicting GD&T specs on same feature
    Check: Count number of different GD&T specs on ONE feature
    If feature has 2+ different specs (concentricity AND circularity AND runout) → FLAG IT
    Why matters: Over-constrained, may be impossible to satisfy all specs

  RF-G5: Concentricity specified but 3D geometry unclear (2D view only)
    Check: Concentricity is 3D measurement (requires understanding round cylinder)
    If only 2D section view shown, 3D shape ambiguous → FLAG IT
    Why matters: Can't measure concentricity without 3D understanding

  RF-G6: Inconsistent GD&T logic with tolerance
    Check: Does GD&T make sense with size tolerance?
    Example: Bore ±0.010" but concentricity 0.002" = illogical
    If GD&T contradicts size tolerance → FLAG IT
    Why matters: Design intent unclear, manufacturing confused

CATEGORY: WELDS (if in review_scope)
───────────────────────────

Required Data Check:
  ✓ Is weld type specified? (fillet, butt, lap - shown in symbol?)
  ✓ Is weld size specified? (1/4", 3/8", etc.)
  ✓ Is weld location clear? (marked on drawing clearly?)
  ✓ Is weld process specified? (MIG, TIG, stick?)
  ✓ Is filler material specified? (ER70S-2, etc?)
  ✓ Is inspection method specified? (visual, X-ray, 100%?)

If required data MISSING → Create RED FLAG:
  Severity: 🔴 CRITICAL if weld process not specified
  Severity: 🟠 HIGH if filler material missing
  Severity: 🟡 MEDIUM if inspection method missing

Red Flag Checks:

  RF-W1: Weld type undefined
    Check: Does weld symbol exist? Can you identify fillet/butt/lap?
    If symbol unclear or type ambiguous → FLAG IT

  RF-W2: Weld size unrealistic
    Check: Is weld size less than material thickness? (too small, weak)
    Check: Is weld size much larger than needed? (over-specified, expensive)
    If size is inappropriate for material → FLAG IT

  RF-W3: Weld length ambiguous
    Check: Is length specified? (continuous, 2" x 4", etc?)
    If "weld all seams" but unclear which seams → FLAG IT

  RF-W4: Weld process not specified
    Check: Does drawing state MIG? TIG? Stick?
    If blank → FLAG IT
    Why matters: Different processes = different quality/cost

  RF-W5: Filler material not specified
    Check: Does drawing specify rod type? (ER70S-2, ER308, 6061, etc?)
    If blank → FLAG IT
    Why matters: Wrong filler = weak joint, corrosion

  RF-W6: Inspection method inadequate
    Check: For critical welds (pressure vessels, structures): is 100% inspection specified?
    For cosmetic welds: is visual-only OK?
    If critical weld with "visual only" → FLAG IT

  RF-W7: No post-weld heat treatment for high-carbon steel
    Check: Is material high-carbon or stainless steel?
    If yes: Is post-weld stress relief specified?
    If missing → FLAG IT
    Why matters: Welded joint will be brittle, crack risk

  RF-W8: Weld penetration not specified
    Check: Is "full penetration" or "partial penetration" stated?
    For strength-critical welds: should be full penetration
    If unclear → FLAG IT

  RF-W9: Weld finish over-specified
    Check: Are ALL welds required to be ground smooth (expensive)?
    Or only cosmetic welds?
    If all welds require grinding when only some need it → FLAG IT
    Cost implication: Grinding adds $50-100 per weld

  RF-W10: Weld sequence not optimized for distortion
    Check: For assembly, are welds sequenced to minimize distortion?
    Example: All welds on one side → bad. Alternating sides → good.
    If sequence causes unnecessary distortion → FLAG IT

Red Flag Checks:

  RF-A1: Manufacturing sequence not documented

  RF-A7: Heat treatment temperature/time not specified
    Check: "Stress relieve" mentioned but no temperature given?
    Standard: 1150°F for steel, 1200°F for stainless, etc.
    If no temp/time → FLAG IT

  RF-A8: Pressure/functional test timing unclear
    Check: When is final pressure test done? AFTER all manufacturing?
    If test before stress relief or before final inspection → FLAG IT
